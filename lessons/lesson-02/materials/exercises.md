# 第 2 课练习与参考答案

## P15｜KV Cache 节省的工作量

输入用[第 2 课实际分词示例](tokenizer-example.json)的 16 个 token，教学输出为「物流」「延误」「了」「。」。每个通过模型的位置计 1 单位。填完两行并求节省比例。

| 方案 | 物流 | 延误 | 了 | 。 | 合计 |
|---|---:|---:|---:|---:|---:|
| 无缓存 | 16 | 17 |  |  |  |
| 有缓存 | 16 |  |  |  |  |

讲师答案：无缓存 16、17、18、19，合计 70。有缓存 16、1、1、1，合计 19。少处理 51 个位置，约 72.9%。这是位置数练习，真实计算量还要考虑每步读取的历史 KV 与注意力配对。

## P23｜一张 80 GB 卡够跑 Qwen3-32B 吗？

按课件的公式和[官方模型配置](https://huggingface.co/Qwen/Qwen3-32B/blob/main/config.json)估算。题设为 1 并发、32,768 个缓存位置、FP16，额外按权重与 KV 之和的 20% 预留。

权重 65.60 GB、KV 约 8.59 GB、课堂总预算约 89.03 GB，高于单卡 80 GB。
