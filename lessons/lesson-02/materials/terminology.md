# 技术页术语对照

首次讲解时同时显示中文与英文；后续可使用已经解释的简称。

| 中文 | 英文与简称 |
|---|---|
| GPU芯片 | GPU Die |
| 高带宽显存 | High Bandwidth Memory，HBM |
| 计算单元 | Compute Units |
| 显存容量 | Memory Capacity |
| 显存带宽 | Memory Bandwidth |
| 缓存、数据通路 | Cache、Datapath |
| 词元、词元编号 | Token、Token IDs |
| 嵌入层 | Embedding |
| 变换器层 | Transformer Layer |
| 注意力 | Attention |
| 查询、键、值 | Query (Q)、Key (K)、Value (V) |
| 前馈网络 | Feed-Forward Network，FFN |
| 输出层 | Output Head |
| 参数、权重 | Parameters、Weights |
| 自回归生成 | Autoregressive Generation |
| 聊天模板、分词器 | Chat Template、Tokenizer |
| 预填充、解码 | Prefill、Decode |
| 浮点运算量 | Floating-Point Operations，FLOPs |
| 键值缓存 | Key-Value Cache，KV Cache |
| 混合专家 | Mixture of Experts，MoE |
| 路由器、专家 | Router、Expert |
| 批处理 | Batching |
| 运行时、余量 | Runtime、Margin |

界面字段与JSON键保留原名，中文解释放在旁边，不把代码字段翻译成另一个键。
